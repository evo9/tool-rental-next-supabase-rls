Назва проєкту:

Розробка MVP системи прокату інструменту — Supabase/PostgreSQL + операторський frontend

Потрібно розробити першу робочу версію системи обліку та прокату інструменту. Це не маркетплейс і не великий CRM-проєкт, а компактний MVP для реальної точки прокату з подальшим масштабуванням.

Технологічно бажано: Supabase + PostgreSQL, Supabase Auth, Supabase Storage, frontend у вигляді PWA/web-app на React/Next.js або аналогічному сучасному стеку.

У нас уже підготовлені й погоджені бізнес-процеси, тарифна логіка, структура бази даних та SQL migration. Потрібно зібрати з цього працюючу систему.

Основний функціонал MVP:

авторизація працівників і ролі OPERATOR / MANAGER / SUPERADMIN;

RBAC + RLS на рівні БД;

база клієнтів: ПІБ, телефон, фото клієнта, фото документа, категорія Platinum/Gold/Silver/Non Grata;

облік кожної фізичної одиниці інструменту окремо;

унікальний QR-код для кожної одиниці;

імпорт початкового переліку інструментів із Excel/CSV;

видача декількох одиниць одному клієнту;

фото кожного предмета при видачі;

автоматична фіксація дати і часу;

планова дата повернення;

часткове та повне повернення;

фото кожного предмета при поверненні;

статуси AVAILABLE / RENTED / UNAVAILABLE / WRITTEN_OFF;

автоматичний розрахунок оренди за затвердженою тарифною логікою;

фіксація прострочень і grace period залежно від категорії клієнта;

історія операцій та Audit Log;

базовий dashboard: доступно / видано / недоступно / активні оренди;

адаптивна робота з телефону, планшета та ПК.

Клієнтський особистий кабінет, онлайн-оплату, Telegram-бот, ПРРО та повноцінну систему бонусів у цей етап включати не потрібно. Архітектура повинна дозволяти додати їх у наступних спринтах.

Від виконавця очікую не просто верстку, а вміння працювати з PostgreSQL/Supabase, RLS, Auth, Storage, SQL migrations і бізнес-логікою. Важлива акуратна структура коду та можливість подальшого розвитку системи іншим розробником.

На виході потрібні: працюючий MVP, репозиторій з кодом, інструкція запуску, налаштована БД, застосовані migrations і коротка технічна документація.

У відгуку прошу вказати: релевантний досвід із Supabase/PostgreSQL, приклади подібних web/PWA-проєктів, орієнтовний термін розробки та бюджет.

Якщо потрібно, можу надати виконавцю готові документи RENT-001…RENT-004, SQL migration і Excel-шаблон для імпорту інструменту.
