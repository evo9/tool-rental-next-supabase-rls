## How to read the tables

|---|---|
| `allowed` | the request worked and returned rows or had an effect |
| `empty` | a read worked but returned nothing: RLS filtered every row (no error) |

## A deactivated employee loses access immediately

The role lives in the `staff` table, not in the JWT. One session (one token) is used before and after the employee is deactivated; the token is never re-issued.
